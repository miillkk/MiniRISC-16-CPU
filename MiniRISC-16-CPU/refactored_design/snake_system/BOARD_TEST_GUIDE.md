# EES331 MiniRISC-16 串口贪吃蛇上板测试

## 1. 连接

1. 关闭占用串口的其他终端软件。
2. 将启动拨码 `SW8` 设置为外部 JTAG 模式 `000000`。
3. 连接板卡电源和下载线。
4. 连接 J8 上方的 USB 接口；该接口连接 PL UART 的 CP2103。
5. 在 Windows 设备管理器中记下对应 COM 号。

PL UART 参数固定为 `115200 baud、8 data bits、no parity、1 stop bit`。

## 2. 拨码初值

第一次测试建议：

```text
SW7..0 = 00000000
```

- `SW1..0=00`：最慢，约每 0.5 秒移动一格。
- `SW2=0`：运行；拨到 1 时暂停。
- `SW7..3`：可在复位前任意设置，用于改变食物随机序列。
- 板上按键 S2/S3 属于 Zynq PS 复位网络，本纯 PL 设计不把它们作为方向键。

## 3. 下载

当前源码已经成功生成并复验 `reports/board/MiniRISC16_Snake.bit`。不要使用计算器、流水灯或其他工程的 bitstream 代替。

1. 打开 `vivado_project/MiniRISC16_Snake.xpr`，或直接打开 Hardware Manager。
2. Open Target → Auto Connect。
3. Program Device。
4. 选择 `reports/board/MiniRISC16_Snake.bit`。
5. 下载完成后按住并松开 S1，让 CPU 从地址 0 启动。

## 4. 打开游戏界面

在 `snake_system` 目录打开 PowerShell：

```powershell
.\tools\snake_terminal.ps1
```

该命令列出当前串口。随后运行：

```powershell
.\tools\snake_terminal.ps1 -PortName COM4
```

把 `COM4` 换成实际端口。终端会寻找 `A5` 帧头并绘制 8×8 棋盘：

- `@`：蛇头。
- `#`：蛇身。
- `*`：食物。
- `.`：空格。

## 5. 操作

- `W/A/S/D` 或方向键：上、左、下、右。
- `R`：Game Over 后重新开始；运行中也可重新开始。
- `Q`：退出电脑端界面。
- `SW2=1`：暂停；拨回 0 后继续。
- `SW1..0`：调整速度。
- S1：硬件复位。

程序会忽略与当前方向相反的输入，例如向右移动时按左不会立即掉头。

## 6. 板上现象

正常启动：

- 数码管显示 `005A0000`，低四位是十六进制分数。
- LED4 亮表示运行。
- LED1..0 显示当前方向。

死亡后：

- 数码管高四位显示 `DEAD`，低四位保留分数。
- LED7 亮。
- 按 `R` 或 S1 重新开始。

## 7. 验收用例

1. 启动后蛇长为 3，向右移动。
2. 分别使用 `W/A/S/D` 转向。
3. 输入反方向，确认蛇继续原方向。
4. 吃到食物后蛇长加 1、分数加 1，食物换位置。
5. 撞墙后显示 `DEAD`，LED7 亮。
6. 按 `R` 后恢复长度 3、分数 0。
7. `SW2` 暂停期间蛇不移动。
8. 切换四档速度，确认移动频率变化。
9. 改变 `SW7..3`，按 S1，确认食物序列发生变化。
10. 连续游戏至少 3 分钟，确认串口帧不丢失且终端不失步。

## 8. 常见问题

- 没有画面：确认连接的是 J8 上方 PL UART，串口未被 Vivado Serial Terminal 或其他软件占用。
- 乱码或丢帧：确认使用 115200 8N1，并先按一次 S1。
- 蛇不移动：检查 SW2 是否为 1。
- 按键无反应：终端窗口必须获得键盘焦点。
- 下载器识别不到：先检查供电、USB、SW8 和 Hardware Manager，不属于串口程序问题。
