# 仿真程序

`system_demo.mem` 是 `tb_system` 使用的 16 位十六进制机器码。每行对应一个字地址，行尾注释给出反汇编和预期副作用。

程序覆盖 13 个有效 opcode、3 个保留 opcode、JZ 成功与失败、无条件跳转、四个寄存器、六种 ALU 功能以及 GPIO 的输入、输出和方向控制。外部测试模型在输入方向的管脚上提供 `8'hA5`；执行完毕后停在地址 `8'h21`。

期望终态：

| 状态 | 期望值 |
|---|---:|
| PC | `8'h21` |
| Z | `1'b1` |
| R0 | `16'h00A5` |
| R1 | `16'h00A5` |
| R2 | `16'h00A5` |
| R3 | `16'h00A5` |
| GPIO_OUT | `8'hA5` |
| GPIO_DIR | `8'h0F` |
| GPIO_IN | `8'hA5` |
