# FPGA 后续工作

当前目录只记录边界，不包含虚构的板级结果。本阶段没有完成或声称完成 XDC、时钟收敛、综合/实现、bitstream、ILA 或上板验证。

继续上板前需要：

1. 获取并核对 EES331 原理图、器件型号、系统时钟频率和复位来源。
2. 确认 8 个 GPIO 的封装管脚、I/O Bank、电压标准、是否允许输出及板上负载极性。
3. 按目标时钟创建 XDC，并完成综合、实现和静态时序检查。
4. 需要在线观测时再加入 ILA，避免把调试逻辑混入当前功能基线。
5. 先验证复位和单路 GPIO 输出，再验证方向切换、输入同步和分支程序。

当前本机 Vivado 2026.1 可完成 Verilog 编译和 elaboration，但实际使用的许可证状态必须在生成 bitstream 或声称板级结果前单独确认。
